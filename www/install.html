1
确认在同一 Wi-Fi 这台电脑和 iPad 连同一个路由器。电脑上的 StarPlay 服务必须开着。
2
Safari 打开本页面 地址是 载入中…。当前已在 Safari 里就继续下一步。
3
点底部「分享」→「添加到主屏幕」 分享图标在 Safari 底部工具栏中间。添加后桌面会出现星映图标。
4
从桌面图标打开 全屏运行、无地址栏，和 App Store 下载的 App 一致。

为什么不是 App Store 的 ipa？
iOS 安装包必须由 macOS 上的 Xcode 编译，Windows 产不出来。 「添加到主屏幕」是苹果官方支持的安装方式（PWA），效果等同原生 App： 独立图标、全屏运行、可后台、有启动画面。 如果要真 ipa，需要一台 Mac 或 GitHub Actions 的 macOS runner 构建（工程已备好，见 starplay/ios/）。
